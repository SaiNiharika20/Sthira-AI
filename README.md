# Sthira AI

## Project Overview
Sthira AI is a household financial planning system designed to help users manage their income, expenses, budgets and savings goals.

## Planned Features
- Income and expense tracking
- Monthly budget management
- Savings goals
- Emergency fund planning
- Financial dashboard
- AI-powered financial insights

## Planned Technology Stack
- Java
- Spring Boot
- React.js
- HTML
- CSS
- JavaScript
- MySQL
- Gemini API

## Project Status
Currently in development.
